## Canonical Algorithms

The D7-B candidate fingerprint V1 is a SHA-256 over newline-joined, length-prefixed components in this exact order: schema version, invoice key hash, hash-index hash, XML SHA-256, PDF SHA-256, and Gmail message-id hash. A component is encoded as decimal name length, colon, name, equals sign, decimal value length, colon, value.

The attachment-set hash is a SHA-256 over newline-joined, length-prefixed XML SHA-256 followed by PDF SHA-256. The implementation uses `Utilities.computeDigest` with the SHA-256 algorithm and lowercase two-character byte encoding. D7-E assigns `invoiceIdentityHash` from `candidateFingerprint`; it does not substitute the separate invoice-key hash.
