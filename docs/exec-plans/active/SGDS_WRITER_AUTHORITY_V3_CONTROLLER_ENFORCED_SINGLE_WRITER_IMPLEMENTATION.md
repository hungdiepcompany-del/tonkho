## Lifecycle and interlock

Use only v3 controller actions. Do not authorize this candidate with v2
`AcquireWriter` or `VerifyWriter`. Every mutation constructs and validates its
candidate before a single durable atomic commit point. A replay/inspection path
must resolve post-commit response loss without blind retry. Legacy v2 state is
read only for exact classification and blocks v3 writer/isolation mutation; it
is never migrated, completed, released, deleted, or manually rewritten.

Writer assignment/acquisition and isolation creation share transition
serialization. A live writer blocks isolation creation; active isolation blocks
writer assignment; concurrent cleanup versus conflicting registration fails
closed.

Canonical durable time is numeric UTC milliseconds; no validation-relevant
comparison may rely on localized DateTime rendering or JSON DateTime coercion.
Windows PowerShell 5.1 and PowerShell 7 must be equivalent.
